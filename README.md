# TubeTunes

YouTube のライブラリ・再生リストを音楽プレーヤーとして再生する拡張機能（Chrome / Vivaldi、モバイル版 Vivaldi 対応）。

## 入れ方
1. [Releases](https://github.com/tamamune/TubeTunes/releases) から最新の `TubeTunes.zip` をダウンロードして展開
2. 拡張機能の管理画面でデベロッパーモードをオン →「パッケージ化されていない拡張機能を読み込む」でフォルダを選ぶ
3. 拡張機能ID が `foogjnjpclbidngnjhbbidfclkpoilhj` になっていることを確認（manifest の `key` で固定）

## ボタンの場所
- モバイル（m.youtube.com）：下部タブの「ショート」の右に「♪ プレイヤー」
- デスクトップ：左のガイドの「ショート」の下（ミニガイドにも表示）

## 機能
- 再生中：再生／一時停止、前へ（3秒以上経過で曲の頭）、次へ、シーク、シャッフル、リピート（オフ→すべて→1曲）、音量（デスクトップ）
- スリープタイマー（15〜90分／この曲の終わり）、動画の表示切り替え、YouTubeで開く
- 画質：自動（省データ）／720p／1080p／1440p
  - YouTube の埋め込みは画質指定のコマンドを無視し、プレーヤーの大きさで画質を決めるため、指定画質の大きさで描画して縮めて表示している
  - 480p 未満には下げられない
- 設定（再生中画面の「⚙ 設定」にまとめてある。プレーヤー操作以外のツール類と下の新機能はすべてここ）
  - 動画内の UI の大きさ：100%〜0.01%（TubeFolio の新プレビューと同じ方式。大きく描いて縮めるので、タイトルやボタンだけが小さくなる）。描画サイズは最大16384pxで頭打ち
  - 広告の早送り：広告中は16倍速・ミュート、スキップできれば自動で押す（既定オン。`ads.js` が埋め込みフレーム内で動く）
- キュー：一覧、タップでジャンプ、削除、「表示中の動画を次に再生」、クリア
- ミニプレーヤー：シートを閉じても下部に残り、ページを移動しても再生が続く。× で停止して閉じる
  - デスクトップ：停止中に一定時間操作がないと自動で隠す（しない／30秒〜30分）
  - ページを再読み込みした直後は表示しない（再生するかプレイヤーを開くと表示）
- 状態（キュー・位置・設定）は保存され、次回は続きから再生できる

## ライブラリ画面
- 「ライブラリ」：「ライブラリに保存」した他の人の再生リスト・アルバム
- 「再生リスト」：自分で作った再生リスト
- 「非表示」：目のアイコンで隠した再生リスト。解除すると元のフォルダに戻る
- フォルダの見出しをタップで開閉（状態は保存）。再生リストをタップで曲一覧を開き「すべて再生」「シャッフル」、曲をタップでそこから再生
- 自分の再生リストかどうかは「公開／非公開／限定公開」の表示と作成者のチャンネルで判定。モバイルでもPC版（WEB）の形式でデータを取得して同じ判定にしている

## 再生の仕組み
- 曲送りは埋め込みプレーヤーの再生リスト機能（`loadPlaylist`、最大200曲ずつ）に任せ、バックグラウンドでも次の曲へ進みやすくしている
- www.youtube.com の上に直接置いた埋め込みは再生を拒否される（エラー152）ため、デスクトップでは m.youtube.com の中継フレーム（`relay.js`）の中にプレーヤーを置いて操作を転送している
- 埋め込みを禁止している動画は自動でスキップ（通知にエラー番号を表示）

## Google Drive 同期
再生中画面の「設定」→「Google Drive 同期」
- 保存先：マイドライブ直下の `TubeTunes-sync.json`（`drive.file` 権限＝この拡張が作ったファイルだけ触れる）
- 対象：シャッフル、リピート、音量、画質、ミニ自動非表示、動画表示、フォルダの開閉、非表示にした再生リスト（キュー・再生位置は端末ごと）
- 自動同期：設定を変えると約5秒後に保存。YouTube を開いたとき Drive の方が新しければ取り込み
- 認証
  - デスクトップ：`chrome.identity.launchWebAuthFlow`（1時間ごとの取り直しも裏で自動）
  - モバイル：タブで Google にログイン → リダイレクト先のURLからトークンを受け取ってタブを閉じる（約1時間で切れたら「再接続」）

### 最初の準備
TubeFolio と同じ OAuth クライアントID を使う。Google Cloud コンソール →「APIとサービス」→「認証情報」→ そのクライアントID（ウェブアプリケーション）の「承認済みのリダイレクトURI」に次を追加：

```
https://foogjnjpclbidngnjhbbidfclkpoilhj.chromiumapp.org/
```

別のクライアントID を使う場合は「初回の準備」に入力して保存。

## ファイル
| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定（MV3） |
| `bridge.js` | ページの `ytcfg`（API設定）をコンテンツスクリプトへ渡す（MAIN world） |
| `content.js` | プレーヤー本体・UI・ライブラリ取得・Drive同期の画面側 |
| `ads.js` | 埋め込みプレーヤー内で広告を16倍速にする |
| `relay.js` | デスクトップ用の中継フレーム（m.youtube.com/robots.txt に埋め込みを置く） |
| `background.js` | Google Drive の認証・保存・読み込み |
| `nav.css` | YouTube のナビに差し込むボタンの見た目 |

## リリースの作り方
`manifest.json` の `version` を上げて main に push すると、GitHub Actions（`.github/workflows/release.yml`）が `v＜version＞` のタグと Release を作り、`TubeTunes.zip` を添付する。
- 同じバージョンのリリースが既にあれば何もしない
- Actions タブの「Run workflow」から手動でも実行できる

## Android 版 Vivaldi でのバックグラウンド再生
